## R4-7.7 Compact medication: today's work only — **Done**

**Rule to implement** (caregiver's own wording):

1. A slot is *today's work* when `DueAt <= endOfToday`.
2. A series with **no open slot due today** does not render in the tiers at
   all → in the evening the table is empty.
3. Within a line that does have today's work, the **next** entry renders in
   a dedicated `tomorrow` bucket that follows morning/noon/evening (the
   bucket key becomes `care_plan.slot.tomorrow`, added to the 4 locales).
4. For a LATE entry, the next entry shows only when
   `next.DueAt - now < now - late.DueAt` — a far-off next slot is noise
   while something recent is still pending.

**Where**: `fillMedTiers` (compact medication only) filters the series'
slots before `seriesTier`/`markSeriesUrgency`, then re-chunks with
`chunkSeriesRows` so the bucket divider still fires on the day change. The
animal Treatment tab keeps its 14-day history view untouched.

**Test**: `TestCompactMedicationShowsOnlyTodaysWork` — a plan with (a) a
late slot today, (b) a slot tomorrow, (c) a series with only a tomorrow
slot: assert the first line keeps today's slot + a `tomorrow` bucket, the
third renders nowhere in the tiers; plus a `TestCompactMedicationEmptyInEvening`
case (every occurrence applied or tomorrow) asserting all three tiers empty.

**e2e**: `/care_plan?view=compact&kind=medication` DOM dump in the 4
locales: `document.querySelectorAll('.plan-med-bucket')` shows only
morning/noon/evening (+ tomorrow when allowed), never a stray later-day
button in a tier body.
