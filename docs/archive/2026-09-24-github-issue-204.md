# GitHub issue #204 — Correctif 24/09

Date: 2026-09-24
Commits: `c20830d`, `cfb706a` on `feature/depupdate`

Source: https://github.com/pijalu/creaves/issues/204

## Reported symptoms

- Cage outtake (`/outtakes/cage?cage=...`) rejected current local date/time as future.
- Localized cage form used the English `Save` submit label.
- Animal and outtake records did not show the stay-length badge.
- Treatment shortcut failed with a Plush reflection error.
- Veterinary shortcut rendered animal `0/0` instead of the animal selector.

## Additional issue found during testing

- Travel shortcut had the same invalid integer `.Value()` expression and displayed animal `0/0` instead of the selector.
- Plan expanded to cover and regress `/travels/new` in every supported locale.

## Implementation

- Cage future-date validation now uses the same naive local wall clock as form binding via `models.FormWallClockNow()`.
- French, German, and Dutch cage templates include their localized outtake form partials.
- Added `stayDurationBucket` render helper and localized labels for `<12H`, `12-24H`, `24-48H`, and `+48H`; rendered on animal and outtake pages in French, English, German, and Dutch.
- Replaced invalid `AnimalID.Value() == 0` expressions with `AnimalID == 0` in treatment, veterinary-visit, and travel new-entry templates for all four locales.
