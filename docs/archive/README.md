# Historical Documentation Archive

This directory preserves superseded research, implementation plans, model/route inventories, bug and fix-round logs, dated assessments, and old E2E results.

**Nothing here is a current setup, design, or operational authority.** Start with [the current documentation index](../README.md) and the project [README](../../README.md).

Files are retained for traceability. Dated filenames identify point-in-time reports; undated filenames usually identify the original plan or subsystem. Some documents describe unimplemented proposals or behavior that has since changed. Verify current code and current guides before reusing any command or schema from this archive.
