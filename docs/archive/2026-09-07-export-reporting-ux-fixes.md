### 6. creaves-console: Excel export reports error (registre_detail PivotTable)

Reported error: Excel recovery log "Removed Feature: PivotTable report from
/xl/pivotTables/pivotTable1.xml" when opening a generated `registre_detail.xlsx`.

**Resolution: no code change required — verified already fixed.** Root cause:
the `registre.xlsx` template ships a pivot cache describing the template's
original 1367 rows; after excelize rewrites the data sheet the stale cache made
Excel strip the pivot table. The Bug 5 fix (`excel/pivot.go`
`updatePivotCaches`, invoked from `excel/excel.go`) rewrites the cache
definition (worksheetSource range, recordCount, refreshOnLoad, emptied cached
records/shared items) and is present and invoked in the console copy.

Reproduced from scratch (console dev server, `/export/excel?query=registre_detail`):
the generated file has `recordCount="10046"` (matches the rewritten
`A1:AG10047` data range), `refreshOnLoad="1"`, 0 cached records, the full
workbook → cache → pivotTable relationship chain intact, all 33 cacheFields
with `numFmtId`, and opens cleanly in LibreOffice with the pivot table intact
on the Stats sheet (10047 data rows). Console quality gates green
(`go vet`, `staticcheck`, full sqlite suite).
