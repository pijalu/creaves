Configuration du webhook

Envoyer les événements vers une instance Creaves Console.

Configuration :
  1. Dans la Creaves Console (récepteur), allez dans Admin → Clés API webhook → Créer une clé et copiez la clé générée.
  2. Activez le webhook ici, collez la clé et renseignez l’URL du webhook de la Console (ex. https://console.example.com/webhook/events).
  3. Enregistrez — le worker d’envoi démarre automatiquement.
