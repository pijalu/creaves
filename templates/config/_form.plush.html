Webhook Configuration

Push events to a Creaves Console instance.

Setup:
  1. In the Creaves Console (receiver), go to Admin → Webhook API Keys → Create Key and copy the generated key.
  2. Enable the webhook here, paste the key, and set the Console's Webhook URL (e.g. https://console.example.com/webhook/events).
  3. Save — the delivery worker starts automatically.
checked<% } %>> When enabled, events will be pushed to the configured webhook URL.
